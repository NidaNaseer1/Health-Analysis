# 🏥 Health Analysis Dashboard – Power BI

## 📌 Project Overview
This project focuses on healthcare data analysis using Microsoft Power BI. The dashboard helps explore patient demographics, medical conditions, and hospital admission patterns through interactive visualizations.

## 🎯 Project Objectives
- Analyze patient demographics and gender distribution.
- Identify patient counts by medical condition.
- Explore hospital admission patterns.
- Present healthcare data through interactive dashboards.
- Generate meaningful insights from healthcare data.

- **Format:** CSV
